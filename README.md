# Хованки

3D-гра українською: картка гравця з нікнеймом, аватаром і кольором, список друзів, запрошення та спільні кімнати до 10 людей. Парк, басейн, школа й ліс мають розмір 120 × 120 метрів. В одиночній грі ти шукач і шукаєш 10 ботів.

## Запуск

Потрібен Node.js 18 або новіший.

```sh
npm install
npm start
```

Відкрий http://localhost:3000. У PowerShell за потреби використовуй `npm.cmd`. Друзі в тій самій мережі відкривають адресу комп’ютера, наприклад `http://192.168.1.15:3000`. Для гри через інтернет цей Node.js-сервер потрібно розмістити на доступному хостингу з підтримкою WebSocket.

1. Створи картку: обери унікальний нікнейм, аватар і колір. Натисни на свою картку, щоб змінити її.
2. У «Гравці та друзі» відкрий чужу картку й натисни «Додати в друзі». Каталог містить гравців саме цього сервера, включно з тими, хто зараз не в мережі.
3. Створи кімнату. Запроси друга з його картки або поділися посиланням / шестизначним кодом.
4. Власник кімнати призначає шукача через картку в лобі. Шукач обирає локацію, власник починає раунд. Якщо гравець один, стартує пошук ботів.
5. W/S або ↑/↓ — рух, A/D або ←/→ — поворот, Пробіл — знайти чи взаємодіяти, Enter — чат, Esc — меню. На вузькому екрані доступні сенсорні кнопки.

Гравці мають 20 секунд, щоб сховатися. Для пошуку підійди до персонажа на 3 метри, повернися до нього й натисни Пробіл. Перешкоди закривають огляд. Перший знайдений гравець стає наступним шукачем; у соло шукачем завжди залишається людина.

Картки та друзі зберігаються в `data/profiles.json`; токен своєї картки — у браузері. Це гостьові профілі без пароля й відновлення облікового запису. Одна картка може бути активною в одній вкладці. Для перевірки кількох гравців використовуй різні браузери або окремі приватні контексти. Дані кімнат зберігаються лише до перезапуску сервера.

## Зображення

Вбудованим інструментом `image_gen` згенеровано та підключено:

- `assets/park.png` — фотореалістичне фото парку для головного екрана.
- `assets/wood.png` — текстура деревини для будиночків, мостів, огорож і парт.
- `assets/bark.png` — текстура кори для дерев і пеньків.
- `assets/stone.png` — текстура каменю для кам’яних поверхонь.

Точні промпти: [assets/prompts.json](assets/prompts.json). Матеріали використовують фотографічні карти кольору й рельєфу; геометрія світу та персонажів залишається стилізованою. Three.js r128 включено локально в `vendor/` разом із ліцензією, CDN для запуску не потрібен.

## Перевірка

```sh
npm test
```

Перевіряє українські нікнейми, редагування, друзів, приватність токенів, кімнати, права вибору шукача/локації, початок раунду, файли та збереження профілів після перезапуску. Тест використовує окремий тимчасовий каталог даних.

Промпт з описом гри: [GAME_BRIEF.md](GAME_BRIEF.md).
