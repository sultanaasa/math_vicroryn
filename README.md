# Hide & Seek Multiplayer

## Run locally

1. Install Node.js 18 or later.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in each player's browser. For friends on the same Wi-Fi, use the host computer's local IP instead (for example `http://192.168.1.15:3000`).

Create a room and start right away for a solo practice round, or share the five-character code with friends to play together. The host can start each new round. Movement uses arrow keys or WASD.
